
# Inventory Management Analysis

## Project Overview
This project analyses inventory data for a fictional food and beverage business.

## Objectives
- Analyse available inventory.
- Calculate daily usage.
- Calculate days of inventory.
- Identify reorder points.
- Perform ABC analysis.

## Dataset
The dataset contains:
- Product name
- Product category
- Available stock
- Monthly usage
- Unit cost
- Supplier lead time

## Tools Used
- GitHub
- Microsoft Excel

## Key Learnings
- Inventory management
- Inventory KPIs
- ABC classification
- Reorder point calculation
